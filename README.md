# 浏览器伪装大师

按域名管理浏览器环境的 Chrome 扩展。为不同网站分别设置时区、语言、浏览器身份、字体保护和模拟位置，也可以根据当前 IP 更新环境，或清理指定站点的数据。

当前版本：**1.4.1**。采用 Manifest V3，支持 Chrome 135 及以上版本，无需安装 Node.js、编译项目或配置 API 密钥。

## 项目特性

| 特性 | 说明 |
| --- | --- |
| 按域名生效 | 每个网站独立配置，可选择包含所有层级子域名；未匹配的网站不应用规则。 |
| 时区与语言 | 设置 IANA 时区、语言优先级和 Intl 默认区域，同步语言请求头，按日期计算夏令时偏移。 |
| IP 环境匹配 | 查询当前出口 IP 的地区信息，匹配时区、国家语言预设及大致位置。 |
| 浏览器身份 | 支持 Windows、macOS、Linux，以及 Chrome、Edge、Firefox、Safari 的兼容身份组合。 |
| 可控随机 | 系统和浏览器可分别固定或随机，一键生成 UA；平台字段自动维护，保存后身份固定。 |
| 字体保护 | 提供常见字体白名单、指定中文字体隐藏和原始字体模式，覆盖常见 Canvas 与 DOM 尺寸探测。 |
| WebRTC 控制 | 使用拨动开关阻断匹配页面的 WebRTC 连接。 |
| 模拟位置 | 设置网页读取的经纬度与精度，无需改变系统定位设置。 |
| 站点数据清理 | 预览范围后清理 Cookie、缓存和本地存储，保留插件中的域名配置。 |
| 页面自检 | 检查已打开目标页面的字体、语言、时区和平台信息。 |
| 本地配置 | 配置保存在浏览器本地。IP 查询仅在主动操作时访问 ipwho.is。 |

性能方面，停用规则不注入脚本，每个匹配页面只接收自己的配置；字体处理使用有上限的缓存，DOM 变化监听按需开启。

## 安装与更新

1. 在 Chrome 地址栏输入 `chrome://extensions`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的 `fake-finger` 文件夹。
4. Chrome 138 及以上：进入插件详情，开启“允许用户脚本”。Chrome 135–137 使用开发者模式开关。
5. 点击浏览器工具栏的扩展菜单，将“浏览器伪装大师”固定到工具栏，方便使用。

更新文件后，在扩展管理页点击本插件的重新加载按钮，再重新打开设置界面并刷新目标网站。

## 快速开始

1. 打开需要配置的网站，点击工具栏中的插件图标。
2. 点击“配置此域名”，进入域名工作台。
3. 选择需要的地区、语言、浏览器身份和隐私设置。
4. 点击“保存域名配置”，允许该站点的访问权限。
5. 刷新目标网站，使新配置生效。

也可以通过弹窗中的“打开域名工作台”管理所有规则。修改、停用或删除规则后，都需要刷新已打开的目标页面。

## 功能使用指南

### 1. 设置域名范围

只填写域名，不填写路径、端口或通配符。

| 规则 | 生效范围 |
| --- | --- |
| `example.com`，不含子域名 | 仅 `example.com` |
| `example.com`，包含子域名 | `example.com`、`www.example.com`、`a.b.example.com` 等 |
| `www.example.com`，包含子域名 | `www.example.com` 及其下级子域名，不包含 `example.com` 或 `api.example.com` |

规则覆盖匹配域名的 HTTP/HTTPS 页面。不能同时保存作用范围重叠的规则；遇到冲突时，编辑已有规则，或取消包含子域名后分别配置。

### 2. 配置地区、语言与位置

在“地区与语言”中选择地区预设，或手动填写：

- **IANA 时区**：例如 `America/Los_Angeles`，用于日期、时间及对应的时区偏移。
- **Intl 默认区域**：例如 `en-US`，用于默认日期和数字格式。
- **语言列表**：例如 `en-US, en`，按优先顺序排列。

需要模拟网页定位时，在“模拟浏览器位置”中开启开关，填写纬度、经度和精度。位置应与选择的时区、地区保持一致。

根据 IP 匹配有两种入口：

| 入口 | 操作结果 |
| --- | --- |
| 工作台“根据当前 IP 匹配” | 查询并填入表单，核对后需点击保存。 |
| 插件弹窗“按当前 IP 更新地区与位置” | 直接更新当前站点匹配的已保存且启用的规则，并启用模拟位置。完成后刷新网页。 |

IP 匹配不是持续追踪：保存后环境固定，切换网络或代理后需再次更新。IP 位置是近似值，语言来自国家预设；分流代理可能让查询服务和目标网站看到不同出口。包含子域名的规则更新后会影响其所有匹配站点。

### 3. 选择或随机浏览器身份

在“浏览器身份”中选择系统、浏览器和版本策略，再点击“一键随机身份”。

例如，系统固定为 **Windows**、浏览器选择 **随机浏览器**，点击按钮后系统仍是 Windows，只随机兼容的浏览器和版本。系统与浏览器都选随机时，会从兼容组合中选择。Safari 仅与 macOS 配对。

版本策略：

- **随机兼容版本**：从可用版本模板中随机选择。
- **优先版本**：使用所选浏览器模板池中的优先版本，减少版本变化。

Chrome 使用本机主版本及前两个主版本的缩减 UA；其他浏览器使用已发布的历史版本模板，并非最新版本承诺。生成后可查看 UA，点击保存后固定生效，不会逐次请求随机。

如果网站提示 UA 或浏览器版本不一致，可以点击“使用真实浏览器身份”，保存并刷新。这会停止身份字段及身份请求头改写，保留其他隐私设置；网站也会读到真实浏览器和系统信息。

### 4. 设置字体保护与 WebRTC

中文字体探测提供三种模式：

- **常见字体白名单+DOM尺寸保护**：限制可探测字体，覆盖常见字体查询及尺寸测量，保护范围较广。
- **隐藏指定中文字体**：隐藏指定字体，保留原有回退字体。
- **保持原始字体行为**：关闭字体保护及相关拦截开销。若某站点出现字体兼容或性能问题，可切换后保存并刷新比较。

WebRTC 开关**开启表示阻断**，可能影响网页语音、视频通话等功能。需要这些功能时可关闭该站点的阻断并刷新。

插件不再额外绘制 Emoji 国旗。按 UA 推断的系统标识可以跟随身份变化，实际 Emoji 字形仍由本机系统决定。

### 5. 使用快捷优化与页面自检

“一键优化 Claude”会填写英文、美西时区、字体保护和 WebRTC 阻断，保留当前浏览器身份和模拟位置。请核对位置与时区是否一致，再保存并刷新。

在另一个标签页打开目标网站后，点击“检测已打开的目标页”，即可查看实际页面的字体、时区、语言和平台信息。

快捷优化和自检均为本插件提供的辅助功能，不代表 Claude 官方认证，也不保证第三方检测得分为零。

### 6. 清理指定站点的数据

1. 在工作台选择已保存的域名规则。
2. 点击“预览选定域名的清理范围”，首次使用时允许清理所需权限。
3. 查看将清理的来源和将关闭的标签页数量。
4. 确认关闭目标标签页并清理，等待完成后重新打开网站。

清理包含 Cookie、HTTP 缓存、LocalStorage、IndexedDB、Cache Storage、Service Worker 和网站文件存储。操作不可撤销，会退出登录，并可能丢失离线数据和未提交表单；插件的域名配置保留。

Cookie 清理可能影响同一可注册主域的其他子站。子域名和非默认端口从历史记录、Cookie 和打开的标签页中发现，无记录的存储来源可能遗漏。历史记录只用于发现范围，不上传、不删除。清理不会删除密码或服务器端记录，也不能保证网站将你识别为首次访问。

## 常见问题

**保存后为什么没有变化？**

先刷新目标页面，检查规则是否启用、域名是否匹配，以及是否允许站点访问和用户脚本。更新插件文件后，还需要在扩展管理页重新加载插件。

**为什么提示界面和后台版本不同？**

旧后台可能仍在运行。使用页面提供的“保存草稿并重载扩展”，或在扩展管理页手动重新加载后再打开工作台。

**为什么 Chrome 的 UA 中也有 Safari？**

这是 Chrome 的正常兼容格式，不代表同时运行两种浏览器。

**为什么修改身份后仍被网站识别？**

UA 模板不会改变实际浏览器引擎、TLS、GPU 或全部运行环境，网站可以交叉比对。恢复真实浏览器身份可减少此类矛盾，但不保证通过所有检测。

**插件会改变 IP 或系统设置吗？**

不会。它修改匹配网页能读取到的部分环境信息，不改变真实网络出口、操作系统时区或已安装字体。Worker、未匹配 iframe、部分新窗口及浏览器底层接口不在完整保护范围内。
