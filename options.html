        覆盖范围与使用限制
        
生效于 HTTP / HTTPS 匹配域名的文档与独立匹配的子框架。修改后请重新加载目标页；关闭规则也需要重新加载。Worker、Service Worker、未匹配的跨域 iframe、about:blank / srcdoc、新窗口的极早期同步探测、浏览器内部页不在完整覆盖范围内。

        
字体处理覆盖常见 DOM 尺寸接口和本页字体枚举，但不能完整覆盖 SVG、跨上下文或所有系统渠道；Emoji 保留本机字形，系统身份不改变真实渲染。Date 的非标准字符串解析、极端历史年份可能仍保留真实环境特征。网页可以识别 JavaScript 改写，不能保证通过所有指纹检测。请求头只修改发往配置域名的请求，不修改发往其他域名的第三方请求。
